# LMS Прототип на Streamlit

## Описание
Прототип системы управления обучением (LMS) с функционалом:
- Модульная структура (Профиль, Уроки, Экзамен)
- Сохранение прогресса (Session State)
- Интерактивные квизы
- Навигация по уровням доступа

## Установка и Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите приложение:
   > **Важно**: Если команда `streamlit` не найдена, используйте `python -m streamlit`:
   ```bash
   python -m streamlit run lms_app.py
   ```

3. Откройте в браузере: http://localhost:8501
